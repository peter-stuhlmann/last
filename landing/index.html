Wie viel hält
euer Server aus?

Gib eine Adresse ein. LAST schickt erst eine, dann Hunderte simulierte Personen los – und sagt dir in einfachen Worten, für wie viele es reicht. Installieren, öffnen, loslegen.

Selbst starten

LAST ist Open Source. Quellcode von GitHub holen und lokal mit Docker starten, dann im Browser localhost:8090 öffnen.

Auf GitHub ansehen ↗ Quellcode als ZIP ↓ 
git clone https://github.com/peter-stuhlmann/last.git
cd last
docker compose up --build

Benutzerhandbuch

So benutzt du LAST – Schritt für Schritt, mit Bildern. Für Entwickler, aber so erklärt, dass es auch alle anderen verstehen. 20 Seiten, PDF.

Handbuch herunterladen (PDF) ↓

So geht’s

  1. Installieren

    Die App bringt alles mit: Testlogik, Oberfläche und den Browser für Abläufe. Sie läuft nur auf deinem Rechner. Lieber selbst? Mit Docker geht es auch.

  2. Adresse eingeben

    KI-Server, API, Website oder ein ganzer Ablauf mit Anmeldung – LAST steigert die Last Schritt für Schritt.

  3. Ergebnis verstehen

    Du bekommst in einfachen Worten, für wie viele Personen es reicht – samt Bericht. Die Dateien liegen in Dokumente/LAST.
