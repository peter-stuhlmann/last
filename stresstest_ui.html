    Das Wichtigste auf einen Blick
    
          
    
            Stell dir den Server als Geschichtenerzähler vor. Jede Frage ist ein Kind, das ihn etwas fragt – er antwortet Wort für Wort.
          
    
          
    
          
    
          
    
            Kleines Wörterbuch: Was bedeuten die Begriffe?
            
    
              
    
                Token – ein Wortstück. Ein Wort besteht meist aus 1–2 Tokens. 100 Tokens ≈ 75 Wörter.Fachbegriff: Token
              
    
              
    
                Wartezeit – wie lange es dauert, bis das erste Wort der Antwort kommt.Fachbegriff: Time to First Token (TTFT)
              
    
              
    
                Tempo – wie viele Tokens pro Sekunde eine Person bekommt, sobald die Antwort läuft.Fachbegriff: Decode-Rate pro Nutzer
              
    
              
    
                Gesamtleistung – alle Tokens pro Sekunde zusammen, für alle Personen.Fachbegriff: Durchsatz (Throughput)
              
    
              
    
                gleichzeitig – wie viele Fragen der Server im selben Moment bearbeitet.Fachbegriff: Concurrency
              
    
              
    
                „normal“ und „fast alle“ – normal: die Hälfte war schneller. Fast alle: 95 von 100 waren schneller.Fachbegriff: Median (p50) und p95
              
    
              
    
                Notizblock – hier merkt sich der Server die laufenden Gespräche. Ist er voll, müssen andere warten.Fachbegriff: KV-Cache
              
    
              
    
                Bruchpunkt – ab hier gibt es Fehler, oder man wartet viel zu lange.Fachbegriff: Überlast / Sättigung
